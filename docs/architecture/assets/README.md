# Architecture Visual Assets

This folder contains static PNG diagrams used by the architecture documentation. Static images are used so the diagrams render reliably in VS Code, GitHub, and PDF exports without requiring a Mermaid extension.

| File | Purpose |
|---|---|
| `docs_map.png` | Documentation reading order and document relationships |
| `system_layers.png` | Layered system architecture |
| `end_to_end_architecture.png` | Complete sensing, edge, cloud, and response workflow |
| `edge_algorithm_pipeline.png` | Edge-side risk-assessment flow |
| `communication_workflow.png` | ESP-NOW, MQTT, AWS IoT, Lambda, storage, and notification flow |
| `mqtt_topic_separation.png` | Telemetry, HRV, and alert topic separation |
| `power_domains.png` | Power domains and rail organization |
| `power_state_machine.png` | Power-state transition model |
| `validation_flow.png` | Recommended validation and evidence flow |
